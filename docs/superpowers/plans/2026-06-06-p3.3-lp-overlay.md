# P3.3 — LP Overlay (cap + mint/burn params with real minOut)

> The capped LP overlay: bind the LP venue under its **15% cap** (tighter than
> the generic 25% per-venue cap) via the P2.5 exposure mechanism, and build
> `mint_lp`/`burn_lp` order params with a **slippage-bounded `minOut`** — never a
> naked `minOut=0` (the design's explicit safety requirement). LP execution
> itself (the Aerodrome LP adapter) is the fill-side counterpart, deferred.

## Decisions (autonomous)
- **Per-venue cap override**: extend `ManagedExposureConfig` with
  `venue_caps: Mapping[str, Decimal]` — a per-venue cap that overrides
  `max_venue_pct`. The LP overlay venue (`aerodrome_lp`) gets the tighter
  `lp_cap` (0.15); other capped venues fall back to `max_venue_pct` (0.25).
  `__main__` wires `capped_venues={"aerodrome_lp"}` + `venue_caps={"aerodrome_lp":
  lp_cap}`. (LP positions are non-zero only once the overlay is built — the cap
  is armed now and binds as soon as it is.)
- **No naked minOut**: a shared `slippage_bounded_min_out(expected_out,
  slippage_bps)` floors `expected_out * (10_000 - slippage)/10_000` and **raises
  if `expected_out <= 0`** — there is no valid zero-quote LP action. mint_lp uses
  it for min LP shares out; burn_lp for min underlying amounts out.
- LP pairs are **stable/blue-chip** on a blue-chip DEX (Aerodrome on Base); the
  pair + pool are named via `pool_id`/`venue`, the executor's LP adapter holds
  the router/pool addresses.

## Design
- `risk/managed_exposure.py`: `ManagedExposureConfig.venue_caps` (default empty);
  checker uses `venue_caps.get(venue, max_venue_pct)`.
- `order_resolver.py`: `slippage_bounded_min_out(...)`; `resolve_mint_lp_params`
  (token_a/b amounts + `amount_lp_min` from `expected_lp_out`; pool_id, venue);
  `resolve_burn_lp_params` (lp_amount + `amount_a_min`/`amount_b_min` from
  expected outs; pool_id, venue).
- `config.py` + `__main__`: read `lp_cap`; wire LP venue cap into the checker.

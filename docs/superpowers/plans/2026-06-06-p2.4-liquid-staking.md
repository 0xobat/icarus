# P2.4 — ETH Liquid Staking (wstETH) — pricing + acquisition

> The ETH sleeve is held as **wstETH** (Lido, non-rebasing). Register wstETH and
> price it via the **wstETH/ETH exchange rate × ETH/USD** (not a 1:1 alias — wstETH
> appreciates vs ETH as staking rewards accrue). Acquisition/rebalancing on Base
> is a **swap** (USDC↔wstETH via the hub), so the existing resolver handles it
> once wstETH is registered + priced — no new order action.

## Decisions (autonomous, documented)
- **LST = wstETH on Base mainnet** `0xc1CBa3fCea344f92D9239c08C0568f6F2F0ee452`
  (18 decimals). Non-rebasing → balance is constant, value grows via the rate.
- **Pricing = exchange-rate, not alias.** `price_usd("wstETH") =
  market.prices["wstETH/ETH"] × price_usd("ETH")`. The rate is sourced by the
  data adapter (a wstETH/ETH Chainlink feed or the contract's `stEthPerToken`) —
  that's the data-layer counterpart, tracked not built here; unit tests inject
  the rate. Missing rate → `KeyError` (fail loud; never silently mis-value).
- **Acquisition = swap on Base**, not L1 Lido staking. wstETH is liquid on Base
  (Aerodrome/Curve); the ETH sleeve rebalances as `USDC↔wstETH` swaps through the
  hub. wstETH is **held, not lent** → not in the yield_router `deployed` set (no
  withdraw/supply legs), exactly like WETH was.
- **LST depeg breaker** (1–2% sustained wstETH/ETH deviation from the rate-implied
  peg) → **deferred to P3** (the design lists "stablecoin + LST depeg" together in
  the P3 portfolio-health monitor). Noted, not built here.

## Design
- `order_resolver`: register `wstETH` on Base mainnet; env override `WSTETH_ADDRESS`.
- `pricing`: add LST exchange-rate handling. `_LST_RATE_KEY = {"wstETH": "wstETH/ETH"}`,
  `_LST_UNDERLYING = {"wstETH": "ETH"}`. `price_usd` multiplies the snapshot rate
  by the underlying's USD price (recurses through the ETH branch).
- `__main__`: add `wstETH` to `_apply_token_overrides`.
- `managed.toml`: ETH sleeve stays `WETH` in the live file until the adapter
  sources the wstETH/ETH rate (data-layer forward dep) — same pattern as cbBTC.
  Flipping `WETH → wstETH` is then a one-line config change.

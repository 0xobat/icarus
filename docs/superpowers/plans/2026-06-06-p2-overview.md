# P2 — Yield Routing + Liquid Staking (Base-first) — Roadmap

**Status:** planned 2026-06-06; execution starts next session. Scope + key forks resolved with the operator.

**Goal (P2):** turn the proven P1 substrate into the full *yield-bearing* managed portfolio — every sleeve earning, rebalanced across lent + staked positions — per `docs/design-managed-portfolio.md` §7.

## Resolved decisions (2026-06-06)
- **Base-first; SOL deferred.** Build the complete portfolio on **Base only** (ETH + wBTC + USDC), prove it end-to-end, THEN add Solana/SOL as a distinct later sub-phase (P2.6). Contains cross-chain risk; doesn't ride on the unproven solana-executor.
- **ETH LST = wstETH (Lido).** Deepest liquidity, non-rebasing, battle-tested ("wstETH-class" default). Used at P2.4.
- **wBTC on Base = cbBTC** (the prevalent Base BTC; WBTC is not canonical on Base) — lent on Aave, or held. Confirm the exact aToken/market at P2.2/P2.3.

## Base-first target (renormalized; SOL's 25% redistributed within the crypto sleeve)
Crypto sleeve 60%, sub-weights ETH 40 / wBTC 35 (SOL 25 deferred) → renormalized ETH 53.3% / wBTC 46.7% of the sleeve:

| Asset | Sleeve | Target weight (of NAV) | Yield mechanic |
|---|---|---|---|
| USDC | Stable | **40%** | Lending (Aave V3, Base) |
| ETH | Crypto | **32%** | Liquid staking (wstETH) |
| wBTC (cbBTC) | Crypto | **28%** | Lending (Aave V3, Base) or held |

Band ±10% absolute weight (unchanged). When SOL lands (P2.6), re-expand to ETH 24 / wBTC 21 / SOL 15 / USDC 40.
